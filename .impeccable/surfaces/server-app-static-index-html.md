# Super-Papagei Visitenkarte 

Scope: server/app/static/index.html, served at "/". Mode: Experience. Public, no data, no download, noindex.

Audience/Job: whoever opens the domain in a browser (family, curious visitors). They should see that a friendly private parrot lives here and smile. The app API stays untouched.

## Direction contract

THESIS: A cassette inlay brought to life: the painted Blutmond-Papagei is the whole page, and it repeats you, like an audiobook you hear again. Refuses the default "404 JSON" and the generic landing page with headline, subcopy and button.

OWN-WORLD: Night navy #0E1424 field, cream ink #F3E6CF, the painted macaw panel (blood-orange moon, crimson, chrome yellow), Archivo extra-condensed black for the title like a 1980s cassette spine. Comic speech bubbles: cream paper, black ink outline, red condensed lettering.

STORY: The moon rises, the parrot appears and blinks now and then. No explanatory text: the page is title plus painting only (user removed the caption and the episode ring). Tapping it makes it say "Super-Papagei!" and repeat it twice, fading like an echo, with optional sound that only plays after the tap.

FIRST VIEWPORT: Title "Super-Papagei" across the top in large extra-condensed cream (one line on desktop, two on phones); below it the square painted panel filling the rest of the viewport height. Nothing else.

FORM: user-pinned direction (no roll), signature: moonrise clip reveal from the moon and the echo bubbles. seed: none (user-pinned, no roll)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
